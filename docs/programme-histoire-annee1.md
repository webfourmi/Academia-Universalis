## Maquette proposée (36 leçons)
Les intitulés ci-dessous sont des objectifs de rédaction, non des leçons publiées. Conserver les identifiants existants et la progression. Périmètre provisoire : origines à environ 600 EC, sans imposer cette périodisation à toutes les régions.
1. Origines : évolution humaine ; migrations ; mobilités ; domestications ; villages ; méthodes archéologiques.
2. Premières civilisations : Uruk ; Égypte ; Nubie ; Indus ; Chine Shang ; premières villes américaines.
3. Asie : Perse ; Inde védique ; Maurya ; Zhou ; Qin ; Han.
4. Méditerranée : Phéniciens et Carthage ; Athènes ; empire athénien ; Alexandre et royaumes hellénistiques ; République romaine ; Auguste et Empire.
5. Autres mondes : Koush ; Aksoum ; Nok ; Mésoamérique ; Andes ; Océanie.
6. Connexions : routes terrestres ; réseaux maritimes ; religions ; techniques ; transformations impériales ; comparaison des civilisations.
## Compétences
Situer dans le temps et l'espace, contextualiser une source primaire, distinguer observation et interprétation, comparer sans postuler une hiérarchie universelle, argumenter avec des preuves, expliciter les incertitudes.
## Évaluation
Exercices corrigés par leçon, analyse documentaire par cycle, dossier comparatif final. Prévoir des cartes et chronologies documentées. Les programmes cités motivent la maquette mais ne constituent pas les preuves des affirmations historiques des futures leçons.
## Suite
Compléter la comparaison institutionnelle en Afrique, Inde, Japon et Océanie. Vérifier les sources historiques originales leçon par leçon, sans prétendre à une relecture indépendante non réalisée. Audit initial : huit leçons de civilisations-data.js, quatre d’antiquite-data.js, huit approfondissements dans histoire-approfondissement.js. Ne pas supprimer les contenus existants.
